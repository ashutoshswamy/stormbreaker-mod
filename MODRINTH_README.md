# Stormbreaker

![Stormbreaker Banner](https://raw.githubusercontent.com/ashutoshswamy/stormbreaker-mod/main/assets/banner.png)

Legendary cinematic Stormbreaker weapon mod for Minecraft Forge `1.20.1` with GeckoLib-powered animation, lightning abilities, throw/recall combat, Thunder Mode, and Bifrost teleport.

## Features

- Custom `Stormbreaker` weapon with legendary rarity, fire resistance, high durability (`4500`), and animated model.
- `Right-click`: summon lightning at your target.
- `Sneak + Right-click`: throw Stormbreaker as a projectile.
- `V`: activate Thunder Mode.
- `B`: cast Bifrost teleport.
- AoE lightning, explosions, weather-based combat bonuses, and custom electric/Bifrost particles.

## Crafting Recipe

![Stormbreaker Crafting Recipe](https://raw.githubusercontent.com/ashutoshswamy/stormbreaker-mod/main/assets/recipe.png)

```text
N T E
S B R
  B
```

Where:
- `N` = Netherite Axe
- `T` = Trident
- `E` = Echo Shard
- `S` = Nether Star
- `B` = Blaze Rod
- `R` = Echo Shard

## Controls

- `V` -> Activate Thunder Mode
- `B` -> Cast Bifrost

## Requirements

- Minecraft `1.20.1`
- Forge `47.3.0`
- Java `17`
- GeckoLib (Forge) `4.4.9`
